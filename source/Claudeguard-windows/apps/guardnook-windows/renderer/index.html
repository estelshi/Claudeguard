      入口节点（可多选）

      多选的节点只是候选，都放进 Clash 的「入口选择」手动组，ClaudeGuard 不会自动切换：当前入口失效时 Claude 会被阻断，需要你在 Clash 里把「入口选择」切到另一个候选。

      固定出口（SOCKS5）

      导入后 ClaudeGuard 会实测公网 IPv4，你确认后才启用保护。账号密码用 Windows 加密保存。

      高级：端口与原始扩展脚本
      没有原脚本时使用透传脚本

      请选择接入 ClaudeGuard 之前的原始脚本，已有分流会保留。不要选择已生成的 ClaudeGuard 脚本。

      把生成的脚本导入 Clash
      导入为独立订阅 先从托盘退出 Clash Verge。导入后重新打开 Clash Verge，选中「ClaudeGuard（出口 IPv4）」并开启 TUN。
      1. 复制生成的脚本含本机凭据，只供本机使用；复制 2 分钟后自动清空剪贴板。
      2. 粘贴到 Clash Verge 的全局扩展脚本订阅 → 全局扩展脚本 → 全选替换并保存，再重载配置。
      3. 保持「规则」模式并开启 TUNClaude 由规则固定走「入口选择 → 固定出口」；首页的当前节点只影响其他应用。
      4. 回到守护页确认实测 IPv4右侧清单全部通过后，在守护页确认实测出口，保护随后开始连续验证。
      1. 导入守护网关节点复制后在 v2rayN 服务器列表按 Ctrl+V，新增 HTTP 节点 GuardNookShare-Gateway（127.0.0.1:19904）。不要设为活动服务器。链接含本机凭据，2 分钟后自动清空。
      2. 开启第二个本地端口v2rayN 参数设置里开启第二个本地监听端口，端口为 10809（本地端口 + 1）。
      3. 导入路由规则并置顶路由设置 → 规则列表 → 从剪贴板中导入规则，提示时选「是」追加（选「否」会替换全部规则）；再从最后一条 ClaudeGuard 规则起逐条「上移至顶」。
      4. 内核选 sing-box 并开启 TUNXray 内核不支持。TUN 开关后控制端口会变，ClaudeGuard 会自动重新找到。
      5. 回到守护页启用保护右侧清单通过后，在守护页点「启用保护」；固定出口连续验证通过才放行。

        可以一键导入独立订阅，也可以按以上步骤手动导入。
