# 变更记录

## 1.0.3

- SOCKS5 出口探测修复（闸门先关、探测失败单独报错）。
- profile-apply 恢复全设备模式和 TUN。
- 首次应用不再把中转地址当作已确认出口。
- 新增「允许 UU 远程直连」开关（默认关）。
- Mac 深色新界面与 Clawd 动效。
- Mac/Windows guard-core 同步。

## 1.0.0

- 首个独立 macOS 发布版本，保留深色顶栏面板、网络监测、固定出口守护、环境检查与运行日志。
- 支持 Clash Verge Rev / Mihomo，以及已有固定出口和 SOCKS5 中转两种接入方式。
- 提供 Apple Silicon 与 Intel 共用的 Universal 安装包。
