# ClaudeGuard / GuardNook 核心网络测试报告

测试日期为 2026 年 11 月 23 日。本机为 Apple Silicon，运行 macOS 26.5.1。本报告记录从原始源码到 1.0.0 发布整理期间的核心功能验证。

## 结论

**守护核心的连接监测、正常放行、异常阻断和恢复放行在隔离环境中通过。** 测试实际启动了 Mihomo 和 sing-box 两种代理内核，并用本机 TCP 对端确认数据能否通过。出口 IP 不符时，已有受守护连接被切断，新连接的数据不能到达上游。正常出口恢复后，守护完成所需的连续确认再放行。

**真实公网固定出口、系统 TUN 和 Windows 客户端导入尚未验收。** 隔离测试使用本机回环端口和测试出口地址。没有对本机正在使用的 Clash 配置、系统代理或 TUN 做切换。Windows 在本机仅完成源码测试和包内容校验。

## 1.0.0 发布包复核

- macOS Universal DMG 和 ZIP 已重新构建，应用内版本为 1.0.0，内部构建号为 1。签名校验、文件 SHA-256、Swift 日志和网络检查、资源检查以及独立源码导出均通过。
- Windows x64 便携 ZIP 和 NSIS 安装程序已重新构建。便携包的应用版本为 1.0.0，EXE 的 Windows 版本资源为 1.0.0.0。包内前端、主进程和守护核心与整理后的源码一致。Windows 真机仍待验证。
- 分拆后两个目录各自运行共享核心测试，均为 206 项通过。Windows 应用测试 37 项通过。
